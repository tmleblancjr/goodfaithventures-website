# Good Faith Ventures LLC — Business Website

Official website project for Good Faith Ventures LLC. Built as a lightweight mobile-first static site for GitHub Pages.

## Deployment

Upload the files from the prepared website archive into the **repository root**, retaining the `assets/` folder. The `index.html` file must appear at the root level, with `assets/logo-360.png` and `assets/logo-800.png` in the assets folder.

In Settings → Pages, choose **Deploy from a branch**, branch **main**, directory **/(root)**. Wait for the GitHub Pages URL to appear before configuring the custom domain.

## Email and DNS

Do not delete or alter Proton Mail MX, SPF, DKIM, DMARC, or domain verification records when connecting the website. Only update the appropriate website A/CNAME records after consulting the GitHub Pages custom domain setup.

## Contact workflow

The initial contact form opens a `mailto:` draft rather than delivering leads to a backend. Test the email address and website thoroughly before outreach. No testimonials or business results are claimed without verification.
